# 时代职业分配

`PopulationJobManager` 根据当前时代为存活人口确定性分配职业，使人口结构随着文明发展变化：原始时代以采集者为主，农业时代加入农民和建造者，工业时代加入工程师，现代时代加入科学家，太空时代加入宇航员。

职业在新世界创建、加载存档和时代升级时重新分配。经济模拟器随后按职业产出食物、木材、石材、金属、电力和科研点数，形成从人口结构到资源增长再到科技推进的闭环。

| 时代 | 关键职业 | 主要产出 |
|---|---|---|
| 原始 | 采集者 | 食物、木材 |
| 农业 | 农民、建造者 | 食物、石材 |
| 工业 | 工程师 | 金属、电力 |
| 现代 | 科学家 | 科研点数 |
| 太空 | 宇航员、科学家 | 科研点数、太空进度 |
