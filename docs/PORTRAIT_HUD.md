# 竖屏 HUD 规范

## 布局

竖屏分为三个区域：顶部资源栏、中部世界地图、底部控制栏。顶部高度约占屏幕 12%，底部约占 22%，中部地图保留至少 60% 的可视区域。

## 顶部资源栏

按顺序显示人口、食物、木材、石材、金属、电力和科研点。每个资源使用 48×48 像素图标、短中文标签和数值；数值变化时使用短暂的颜色反馈，但不能遮挡地图。

## 时代与任务卡

顶部资源栏下方显示当前时代、时代推进提示和科技进度。进入太空时代后切换为太空任务卡，显示“等待发射”“卫星已部署”“空间站运行中”“深空探测中”或“载人探索中”。

## 底部控制栏

底部按钮至少包含暂停、减速、正常、加速、资源赠送、降雨、陨石、科技树和太空任务。所有触控区域不小于 48×48 像素，按钮间隔至少 8 像素，并支持横向滚动以避免在小屏幕上重叠。

## 状态绑定

`PortraitHudState.FromWorld` 将模拟层转换为 UI 可读状态。`PortraitHudController.StateChanged` 负责通知实际 Text、Image、Slider 和 Button 组件刷新。UI 不直接修改模拟字段，所有操作通过控制器公开方法进入领域系统。
