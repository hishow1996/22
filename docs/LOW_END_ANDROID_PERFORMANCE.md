# 老安卓设备性能方案

项目目标是优先保证低端 Android 设备的稳定帧率和可控内存，而不是盲目追求高画质。`MobilePerformanceSettings` 默认启用低端预设：关闭垂直同步和抗锯齿、禁用阴影、降低 LOD、限制纹理分辨率、减少粒子射线预算，并将目标帧率设为 30 FPS。设备性能较好时可以通过 Inspector 或按钮切换平衡预设。

## 已完成的 CPU 优化

人口单位层不再每帧同步所有单位，只在 `PopulationMovementSystem.Revision` 改变时更新位置。文明事件面板不再每帧重建字符串，而是订阅事件日志变更；科技树面板仅在时代升级、研究完成或加载存档时重建节点。

## Unity 场景接入

建议将 `MobilePerformanceSettings` 添加到启动场景中的常驻对象，并在 Android 发布配置中默认保留低端预设。地图使用固定尺寸和 Tilemap，人口单位使用对象复用方向扩展，不应为每个模拟日创建临时 GameObject 或字符串集合。

## 目标预算

| 项目 | 低端目标 |
|---|---:|
| 目标帧率 | 30 FPS |
| 单帧预算 | 约 33 ms |
| 地图规模 | 64 × 96 默认地图 |
| 事件日志 | 最近 40 条 |
| 事件面板 | 最近 8 条 |
| 阴影 | 关闭 |
| 抗锯齿 | 关闭 |

真实设备验证仍需在目标 Android 手机上用 Unity Profiler 检查主线程、渲染线程、GC Alloc 和内存峰值；静态检查不能替代真机测量。
