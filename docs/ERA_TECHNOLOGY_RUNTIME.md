# 时代推进与科技运行时

`TechnologyState` 保存已解锁科技，并根据当前时代计算可研究节点。原始时代默认解锁“掌握火种”；其他科技必须满足时代、前置科技和科研点数条件。

当经济循环满足时代推进条件时，控制器会：

1. 推进 `EraProgression`。
2. 解锁该时代的零成本基础节点。
3. 发出 `EraAdvanced` 事件。
4. 刷新道路、覆盖层和时代建筑。
5. 让 HUD 重新计算已解锁和可研究科技数量。
6. 通过 VFX Presenter 提供升级提示/特效回调。

科技解锁列表会写入 JSON 存档，加载时恢复。旧存档没有该字段时使用空列表；世界初始化会默认解锁原始时代火种。
